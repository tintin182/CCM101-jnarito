# ☁️ Cloud Provider Comparison

This comparison looks at how the three major public cloud providers provide similar infrastructure services. Although the services have different names, they generally serve similar purposes when building and managing cloud environments.

The information in this comparison is based on the official documentation of Amazon Web Services (AWS), Microsoft Azure, and Google Cloud.

---

## 🏗️ Infrastructure Service Comparison

| Infrastructure Component | Amazon Web Services (AWS) | Microsoft Azure | Google Cloud Platform (GCP) |
|---|---|---|---|
| **💻 Compute** | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| **🗄️ Storage** | Amazon S3 | Azure Blob Storage | Cloud Storage |
| **🌐 Networking** | Amazon VPC | Azure Virtual Network | Virtual Private Cloud (VPC) |
| **🔐 Identity and Access Management (IAM)** | AWS IAM | Azure RBAC | Google Cloud IAM |

---

## ❓ Guide Questions

### 1. Which cloud provider offers the broadest range of services?

AWS offers a broad range of cloud services covering areas such as computing, storage, networking, databases, security, and analytics. Its large selection of services makes it suitable for organizations with different types of cloud requirements (Amazon Web Services, n.d.).

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would recommend Microsoft Azure for an organization that primarily uses Microsoft products. Azure works closely with Microsoft's ecosystem, making it a practical choice for organizations already using Microsoft technologies and services (Microsoft, n.d.).

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

Google Cloud is widely recognized for its capabilities in Artificial Intelligence, Machine Learning, and Kubernetes. Google also created Kubernetes, making Google Cloud a strong option for organizations working with containers and cloud-native applications (Google Cloud, n.d.).

### 4. What similarities did you observe among the three cloud providers?

All three providers offer services for the basic parts of cloud infrastructure, including compute, storage, networking, and identity and access management. The names and specific features differ, but the main purpose of these services is similar across the three platforms (Amazon Web Services, n.d.; Google Cloud, n.d.; Microsoft, n.d.).

## 🎯 Conclusion

AWS, Microsoft Azure, and Google Cloud provide the core infrastructure needed to build cloud-based systems. While each provider uses different service names and features, the basic concepts remain similar: compute resources run workloads, storage keeps data, networking connects resources, and identity and access management controls access to those resources.

Understanding these similarities makes it easier to compare cloud platforms and determine which provider may be appropriate for a specific organization's requirements.
