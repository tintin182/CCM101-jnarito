## 👋 Welcome

Welcome to my **CCM101 – Cloud Computing** portfolio.

This repository contains my laboratory activities, projects, documentation, and reflections throughout the course. It covers topics including **Linux, cloud infrastructure, networking, storage, Git, GitHub, and multi-cloud platforms**.

Each laboratory represents a part of my learning journey as I develop practical skills and gain a better understanding of how cloud technologies are used in modern computing environments.

## 📖 About This Portfolio

This portfolio was created as part of **CCM101 – Cloud Computing** at the University of Eastern Pangasinan.

Throughout the semester, I document the activities and exercises I complete, including technical outputs, screenshots, research, and personal reflections.

The goal of this portfolio is not only to submit laboratory requirements but also to keep a record of my progress and experiences while learning cloud computing.

Alongside cloud technologies, I am also interested in **UI/UX Design, Web Development, Mobile Application Development, and Basic Computer Networking**. These areas allow me to combine technical skills with creativity and problem-solving.
