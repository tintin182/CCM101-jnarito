# ☁️ Cloud Platform Comparison

## 📊 Major Cloud Platform Comparison

| Category                   | AWS                                                                              | Microsoft Azure                                                               | Google Cloud Platform                                                                     |
| -------------------------- | -------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| **🚀 Launch Year**         | **2006**                                                                         | **2010**                                                                      | **2008***                                                                                 |
| **💻 Compute Service**     | Amazon EC2                                                                       | Azure Virtual Machines                                                        | Google Compute Engine                                                                     |
| **💾 Storage Service**     | Amazon S3                                                                        | Azure Blob Storage                                                            | Google Cloud Storage                                                                      |
| **🌐 Networking Service**  | Amazon VPC                                                                       | Azure Virtual Network                                                         | Google Virtual Private Cloud (VPC)                                                        |
| **🔐 Identity Service**    | AWS IAM                                                                          | Microsoft Entra ID                                                            | Google Cloud IAM                                                                          |
| **⭐ Primary Strength**     | Broad range of cloud and infrastructure services                                 | Strong integration with Microsoft technologies and enterprise environments    | Data, AI/ML, analytics, and Kubernetes capabilities                                       |
| **🏢 Ideal Organizations** | Startups, enterprises, and organizations needing a broad cloud service portfolio | Organizations using Microsoft technologies and hybrid enterprise environments | Organizations focused on AI/ML, data analytics, containers, and cloud-native applications |

> **Note:** Google Cloud's **2008** launch year refers to the beginning of Google's cloud platform through Google App Engine. Google Cloud Platform subsequently expanded into a broader collection of infrastructure and platform services.

---

## 1. 🔍 Which cloud provider offers the broadest range of services?

AWS offers the broadest range of services among the three platforms, with a large portfolio covering areas such as compute, storage, databases, networking, security, analytics, artificial intelligence, and application development. AWS describes its current portfolio as offering more than 240 comprehensive services, giving organizations many options for building different types of cloud architectures (Amazon Web Services, n.d.-a).

## 2. 🔗 Which provider best integrates with Microsoft technologies?

Microsoft Azure best integrates with Microsoft technologies because it is part of the Microsoft ecosystem and provides services designed to work with Microsoft products and technologies. Azure supports Windows-based workloads, Microsoft Entra ID, Microsoft services, and other enterprise technologies, making it particularly suitable for organizations that already rely heavily on Microsoft's ecosystem (Microsoft, 2026a).

## 3. 🤖 Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is a strong choice for Artificial Intelligence and Kubernetes because of its extensive AI and data services and its managed Google Kubernetes Engine (GKE). Google Cloud also has a strong connection to Kubernetes technology, while GKE provides a managed Kubernetes platform for deploying and operating containerized applications at scale (Google Cloud, n.d.-a; Google Cloud, n.d.-b).

## 4. 🎯 Which cloud platform would you personally choose and why?

I would personally choose **Google Cloud Platform** because I am interested in cloud-native development, artificial intelligence, data analytics, and Kubernetes. Google Cloud provides services such as Compute Engine, Cloud Storage, Cloud SQL, and Google Kubernetes Engine, which provide a strong foundation for developing and deploying modern applications (Google Cloud, n.d.-a; Google Cloud, n.d.-b).

## ⚙️ Service Comparison

The following services provide comparable functions across the three cloud platforms:

| Service Category           | AWS        | Microsoft Azure                | Google Cloud Platform          |
| -------------------------- | ---------- | ------------------------------ | ------------------------------ |
| **🖥️ Virtual Machine**    | Amazon EC2 | Azure Virtual Machines         | Compute Engine                 |
| **🗄️ Object Storage**     | Amazon S3  | Azure Blob Storage             | Cloud Storage                  |
| **🔐 Identity Management** | AWS IAM    | Microsoft Entra ID             | Cloud IAM                      |
| **🛢️ SQL Database**       | Amazon RDS | Azure SQL Database             | Cloud SQL                      |
| **☸️ Kubernetes**          | Amazon EKS | Azure Kubernetes Service (AKS) | Google Kubernetes Engine (GKE) |

These services represent comparable categories across the three providers. Google Cloud's official comparison documentation specifically maps Compute Engine with Amazon EC2 and Azure Virtual Machines, GKE with Amazon EKS and Azure Kubernetes Service, and Google Cloud IAM with AWS IAM and Azure identity-management services (Google Cloud, 2024).

---

## 📝 Summary

AWS, Microsoft Azure, and Google Cloud Platform all provide major cloud computing capabilities, including computing, storage, networking, databases, and identity management. However, each platform has areas where it can be particularly suitable: AWS provides a very broad service portfolio, Azure is particularly suitable for Microsoft-centered environments, and Google Cloud is a strong option for data, AI/ML, and Kubernetes workloads.

The best cloud platform therefore depends on the organization's technical requirements, existing technologies, workload characteristics, and business objectives rather than simply choosing the most popular provider.
