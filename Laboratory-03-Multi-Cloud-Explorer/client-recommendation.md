# ☁️ Cloud Platform Recommendation Challenge

## Checkpoint 4 - Client Recommendation

This checkpoint evaluates four different business scenarios and recommends the most suitable cloud platform for each client. Each recommendation is based on the client's specific requirements, followed by relevant cloud services that could support the proposed solution.

---

## 🚀 Client A - Startup Company

### 📋 Scenario

A startup company wants to launch a new mobile application. Its budget is limited, but it expects rapid growth within the next few years.

### 🎯 Recommendation: **Amazon Web Services (AWS)**

AWS is the recommended cloud platform for the startup because it provides scalable cloud services that can support a mobile application as the company grows. AWS also provides startup-focused programs such as AWS Activate, which can provide eligible startups with promotional credits that help reduce initial cloud infrastructure costs. The startup could use **Amazon EC2** to provide scalable computing resources, **Amazon S3** to store application files and user data, and **Amazon RDS** to manage its relational database. These services allow the company to begin with the resources it needs and increase capacity as its application gains more users.

### 🛠️ Services the Client Could Use

- **Amazon EC2** — Scalable cloud computing for application servers.
- **Amazon S3** — Storage for application files, images, backups, and other data.
- **Amazon RDS** — Managed relational database service for application data.
- **AWS Activate** — Startup program that can provide eligible startups with AWS credits and other resources.

---

## 🏫 Client B - University

### 📋 Scenario

A university already uses:

- **Windows Server**
- **Microsoft 365**
- **Active Directory**

The university wants to migrate some of its services to the cloud.

### 🎯 Recommendation: **Microsoft Azure**

Microsoft Azure is the recommended cloud platform for the university because it already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong support for Windows Server workloads and Microsoft identity technologies, allowing the university to build a cloud or hybrid environment that works with its existing Microsoft infrastructure. The university could use **Azure Virtual Machines** to migrate Windows Server workloads, **Microsoft Entra ID** to manage cloud identities and access, and **Azure Blob Storage** to store files and other university data. **Azure Migrate** can also help the university discover, assess, and migrate existing applications, infrastructure, and data to Azure.

### 🛠️ Services the Client Could Use

- **Azure Virtual Machines** — Run Windows Server workloads in Azure.
- **Microsoft Entra ID** — Manage identities, authentication, and access.
- **Azure Blob Storage** — Store documents, files, backups, and other unstructured data.
- **Azure Migrate** — Discover, assess, and migrate existing workloads to Azure.

---

## 🤖 Client C - AI Research Company

### 📋 Scenario

A research company develops Artificial Intelligence and Machine Learning applications that require high-performance computing.

### 🎯 Recommendation: **Google Cloud Platform (GCP)**

Google Cloud Platform is the recommended cloud platform for the AI research company because it provides strong capabilities for Artificial Intelligence, Machine Learning, and high-performance computing. Google Cloud offers specialized AI and ML services and scalable compute resources that can support demanding research workloads. The company could use **Compute Engine** for high-performance virtual machines, **Google Kubernetes Engine (GKE)** for containerized AI and ML workloads, and **Vertex AI** for developing, training, and deploying machine learning models. These services can provide the computing and machine learning infrastructure needed for research applications.

### 🛠️ Services the Client Could Use

- **Compute Engine** — Provides scalable virtual machines for high-performance computing workloads.
- **Google Kubernetes Engine (GKE)** — Runs and manages containerized AI and ML applications.
- **Vertex AI** — Provides tools for building, training, and deploying machine learning models.

---

## 🌎 Client D - Global E-Commerce Company

### 📋 Scenario

A multinational online shopping company serves customers around the world and requires highly available infrastructure with automatic scaling.

### 🎯 Recommendation: **Amazon Web Services (AWS)**

AWS is the recommended cloud platform for the global e-commerce company because it provides a broad range of scalable and highly available cloud infrastructure services. AWS supports deployments across multiple geographic Regions and Availability Zones, allowing applications to be designed for high availability and resilience. The company could use **Amazon EC2 Auto Scaling** to automatically adjust computing capacity, **Elastic Load Balancing** to distribute incoming application traffic, and **Amazon RDS** to provide a managed relational database for the e-commerce platform. These services can help the company handle changes in customer demand while maintaining application availability.

### 🛠️ Services the Client Could Use

- **Amazon EC2 Auto Scaling** — Automatically adjusts computing capacity based on demand.
- **Elastic Load Balancing (ELB)** — Distributes incoming traffic across application resources.
- **Amazon RDS** — Provides a managed relational database for e-commerce applications.
