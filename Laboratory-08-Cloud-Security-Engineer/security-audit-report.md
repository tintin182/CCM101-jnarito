# 🛡️ Security Audit Report

## 🔑 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving users only the access they need to do their work. This is important for cloud accounts because it helps prevent people from accessing files or systems they are not supposed to use.

## 🎯 2. Attack Surface

An attack surface refers to the parts of a virtual machine that attackers could use to get in. For example, open ports, running services, and applications can create ways for attackers to access the server, so unnecessary ones should be turned off.

## 🚫 3. Default Deny Policy

A Default Deny Policy means blocking incoming connections unless they are specifically allowed. This is safer because the server does not accept unknown connections by default, so administrators do not have to find and block every possible attacker one by one.
