# 📝 Mission Reflection

Throughout this laboratory activity, I learned why automation is important in cloud computing. Managing hundreds of servers manually takes a lot of time and can lead to mistakes. With automation, tasks such as creating backups can run automatically and help prevent data loss. However, automation also has risks. For example, a small mistake in a script running on 1,000 servers could damage or delete important files. This is why scripts should be tested carefully before they are used on actual systems.

Writing a Bash script was different from creating a Docker Compose YAML file in Mission 6. In Bash, I wrote commands that run step by step to create and compress a backup of application data. In Docker Compose, I used a YAML file to define and manage application containers and their services. Both tools make cloud tasks easier, but they are used for different purposes.

Looking back at my previous laboratory activities, my understanding of cloud computing has improved. I started by learning the basics of cloud services and gradually explored virtual machines, containers, networking, storage, deployment, and security. I also became more comfortable using Linux commands and documenting my work in GitHub. These activities helped me understand how different cloud technologies work together in real situations.

Among the roles I explored, I enjoyed being a **Cloud Deployment Engineer** the most because I was able to work with Docker Compose and deploy applications. I liked learning how different services work together and how containers make application deployment easier. This experience encouraged me to continue improving my skills in Linux, Docker, and cloud infrastructure.

Overall, this semester taught me that becoming a cloud engineer requires continuous learning and hands-on practice. I know I still have a lot to learn, but I am more confident in using cloud tools and solving technical problems than when I started. I look forward to applying these skills in future projects and improving my knowledge of cloud computing.
