# 🔎 The Language of Automation

## 1. Bash Script

A Bash script is a file that contains Linux commands that can run together automatically. The `#!/bin/bash` line at the beginning tells Linux to use Bash to run the script.

## 2. Variables

Variables store values, such as folder paths, that can be reused in a script. For example, `$BACKUP_DIR` allows us to use the same backup folder path without typing it repeatedly, making the script easier to update.

## 3. Cron Job

A cron job is a scheduled task in Linux that runs commands or scripts at a specific time. It is useful in cloud operations because it can automate repeated tasks, such as creating backups every night, without requiring someone to run them manually.
